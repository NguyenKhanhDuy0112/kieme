# Changesets

Mỗi thay đổi người dùng thấy được → thêm 1 changeset cho `@kiemi/desktop`:

```bash
pnpm changeset          # chọn @kiemi/desktop, mức patch/minor/major, viết 1 câu tiếng Việt
```

Câu viết ở đây thành mục "Có gì mới" trong app và ghi chú trên GitHub Releases — viết cho tester, không dùng thuật ngữ kỹ thuật.
Phát hành: xem `docs/RELEASE-CHECKLIST.md`.
